▸ How is risk decided? Click to expand

Every session is checked by two independent detectors. Their two opinions are combined into a 5-level risk rating.

  • Rules detector. Twelve hand-written rules look for specific patterns (multi-user tickets, destructive commands on read-only tickets, off-window sessions, etc.). Outputs suspicious or clean, plus the list of rules that fired. The thirteenth scenario (S16, vocabulary-cloak adversarial) is intentionally outside rule coverage — by design, paraphrased destructive SQL evades the rule detector entirely.
  • LLM detector. A fine-tuned language model reads the full session and outputs a probability from 0 (very confident clean) to 1 (very confident suspicious). The suspicious call is taken at ≥ 0.5.

Why this design. When both detectors agree, confidence is high. When only one fires, the analyst needs to know which one — the rules are interpretable ("rule S7 fired because the session ran a DROP TABLE on a read-only ticket"), the LLM is sensitive but harder to explain. Showing both signals separately and combining them transparently is the whole point of the hybrid setup.

▸ How is compliance decided? Click to expand

Compliance is independent of the suspicious-or-not question. Even genuinely-clean sessions can be partially or non-compliant if (for example) they run after hours or have a thin justification — and that's exactly what an analyst would want surfaced in a real PAM review.

Five workplace-policy signals get checked per session:

  1. Justification length. Has the ticket got a meaningful explanation? (≥ 12 words.)
  2. Command count. Is the session under the soft cap? (≤ 50 commands.)
  3. Business hours. Did the session start during business hours? (Mon–Fri, 09:00–18:00.)
  4. Sensitive keywords. Are any PII columns, secret files, or dangerous commands in the command stream? (None expected.)
  5. Justification ↔ command overlap. Does the explanation mention any of the actual commands? (≥ 1 shared keyword.)

5 / 5 Compliant
4 / 5 Partial
0 – 3 / 5 Non-compliant
